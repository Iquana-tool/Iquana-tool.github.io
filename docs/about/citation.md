# Citing IQUANA

If IQUANA contributed to work you are publishing, please cite it.

!!! warning "Citation details are not final yet"
    A `CITATION.cff` file and a canonical reference (with DOI) are still to be
    added to the [`iquana-tool`](https://github.com/Iquana-tool/iquana-tool)
    repository. Until then, please cite the software by name, the institutions,
    and the repository URL — and check back before submitting.

An interim reference:

```text
IQUANA - Intelligent QUantification, ANnotation and Analysis.
German Research Center for Artificial Intelligence (DFKI),
in partnership with the Helmholtz Institute for Functional
Marine Biodiversity (HIFMB).
https://github.com/Iquana-tool/iquana-tool
```

If you need a formal citation for a submission with a deadline, please write to
[robert.leist@dfki.de](mailto:robert.leist@dfki.de).
